    What this is

    A real, playable first room. Six spaces, several small interactions, and a Milo who can move, jump, examine objects, tend a garden, forge a lantern, connect stars, and discover surprises. No account, server, build step, or internet connection is required.

    This is an annex, not a replacement for the Phoenix, the Mirror, the Spine, or the other rooms of Aion Tekmirion.

    What it isn't (yet)

    The wandering demo is not an LLM. Milo's movement and dialogue here follow JavaScript rules. For an actual AI to choose actions, an external model would need a secure connection to the world's observation-and-action interface.

    That interface is exposed as window.MiloWorld for a future collaborator. Nothing silently sends conversations or game data anywhere.
